## 🌟 What is Zenith?

Zenith is a **single-file HTML productivity app** that combines task management, goal tracking, energy management, pomodoro focus sessions, habit tracking, and intelligent analytics — all in one beautiful, immersive interface.

### What Makes Zenith Different?

1. **Energy-First Planning** — Match tasks to your natural energy rhythms
2. **Intelligent Learning** — Gets smarter the more you use it
3. **Beautiful UI** — Immersive themes with liquid glass design
4. **All-in-One** — No need for multiple apps
5. **Privacy-First** — All data stored locally, no servers
6. **Zero Setup** — Just open the HTML file and start

## 📚 Complete User Guide

### 🌅 Morning Ritual

**Purpose:** Start your day with intention and clarity.

**Steps:**
1. **Energy Check** — How do you feel? (High/Medium/Low)
2. **Carry-over** — Which unfinished tasks from yesterday matter today?
3. **Intentions** — What are your top 3 priorities?
4. **Gratitude** — One thing you're grateful for
5. **Summary** — Review and begin your day

**Tips:**
- The ritual appears once per day
- Your energy level determines which tasks are suggested
- You can skip the ritual, but it's recommended for best results
- Takes only 2-3 minutes

### 📋 Tasks — Your Daily Execution

#### Creating Tasks

1. Click **"+ Add Task"** button
2. Fill in:
   - **Title** (required) — What needs to be done?
   - **Description** — Additional context
   - **Priority** — Critical / High / Medium / Low
   - **Energy Required** — Deep Work / Medium / Light
   - **Date** — When to do it
   - **Category** — Work, Study, Personal, etc.
   - **Time** — Start and end time (optional)
   - **Duration** — Estimated minutes
   - **Link to Goal** — Connect to a larger objective
   - **Subtasks** — Break it down into steps

3. Click **"Save Task"**

#### Smart Features

**Duration Suggestions:**
- Type a task title and blur the field
- If you've done similar tasks before, Zenith suggests a duration
- Example: "Code authentication" → "Based on 5 similar tasks, this usually takes 180 minutes"

**Breakdown Warnings:**
- Tasks over 2 hours show a warning
- Zenith suggests breaking them into subtasks
- If the title matches a template (Code Feature, Write Article, Meeting, Learning), subtasks are auto-suggested

**Energy Matching:**
- Deep Work tasks are highlighted when you have high energy
- Light tasks are suggested when energy is low
- Medium tasks work for any energy level

#### Task Actions

- **✓ Complete** — Mark as done, add notes and actual time
- **→ Defer** — Move to tomorrow (tracks defer count)
- **⚡ Do Now** — Focus on this one task (hides others)
- **✏️ Edit** — Modify any details
- **🗑️ Delete** — Remove permanently

#### Views

**Sidebar Views:**
- **Today** — Tasks for today only
- **Week** — Next 7 days
- **All** — Everything

**Calendar View:**
- Click any date to see tasks
- Dots indicate task count
- Color-coded by priority

### 🎯 Goals — Your Strategic Planning

#### Planning Structure

Zenith uses a 4-level hierarchy:

```
Life Areas (Timeless)
    ↓
Quarterly OKRs (12 weeks)
    ↓
Monthly Themes (4 weeks)
    ↓
Weekly Sprints (7 days)
    ↓
Daily Tasks
```

#### Life Areas

Six core pillars of a balanced life:
- 💪 **Health** — Physical and mental wellbeing
- 💼 **Career** — Professional growth and work
- ❤️ **Relationships** — Family, friends, connections
- 📚 **Learning** — Skills, knowledge, education
- 💰 **Finance** — Money, investments, security
- 🌟 **Personal** — Hobbies, creativity, self-care

#### Creating Goals

1. Click **"+ Add Goal"** in Goals view
2. Choose **Horizon Level**:
   - **Life Area** — Timeless pillar (e.g., "Maintain excellent health")
   - **Quarterly** — 12-week objective (e.g., "Ship 3 major features")
   - **Monthly** — 4-week theme (e.g., "Master React Hooks")
   - **Weekly** — 7-day sprint (e.g., "Complete authentication module")

3. Add **Key Results** (for Quarterly goals):
   - Measurable outcomes
   - Example: "90% test coverage", "10 customer interviews"

4. **Link to Parent** — Connect to a higher-level goal

#### Goal Health Scores

Zenith automatically tracks goal health:
- **Healthy (70-100)** — ✅ Great progress, keep going
- **At-Risk (40-69)** — ⚠️ Needs attention
- **Stalled (0-39)** — 🔴 No recent activity

**Factors:**
- Recent activity (last 7 days)
- Progress rate (completed vs total tasks)
- Task count (goals with no tasks are stalled)

#### Horizon Views

Switch between planning levels:
- **Life Areas** — See all 6 pillars
- **Quarterly** — 12-week timeline
- **Monthly** — 4-week breakdown
- **Weekly** — 7-day sprint view

### 🍅 Pomodoro — Deep Focus Sessions

#### What is Pomodoro?

A time management technique:
- **25 minutes** of focused work
- **5 minutes** of break
- After 4 sessions, take a **15-minute** long break

#### Using Pomodoro in Zenith

2. Choose a **Theme** (Night, Sunset, Ocean, Forest, Space)
3. Choose **Ambient Sound** (Rain, Waves, Forest, Cafe, White Noise, or None)

## 🧠 Intelligent Features

### How Zenith Learns

#### 1. Task Duration Learning

**What it does:**
- Tracks estimated vs actual time for every completed task
- Groups tasks by type (coding, writing, meeting, learning, design)
- Calculates average duration and accuracy

**How it helps:**
- After 3+ similar tasks, suggests durations automatically
- Shows your estimation accuracy (e.g., "You typically underestimate by 30%")
- Improves planning over time

**Example:**
```
You: Create task "Write blog post"
Zenith: "Based on 7 similar tasks, this usually takes 180 minutes 
         (you typically underestimate by 25%)"
```

#### 2. Energy Pattern Tracking

**What it does:**
- Records your energy level each day (morning/afternoon/evening)
- Analyzes 30-day patterns
- Identifies your peak productivity times

**How it helps:**
- Predicts best work times (e.g., "You're most productive in the morning")
- Suggests recovery actions when energy is low
- Matches tasks to your current energy

**Example:**
```
You: Set energy to "Low"
Zenith: Shows only Light tasks
        Suggests: "Take a 10-minute walk" or "Switch to light tasks"
```

#### 3. Energy Budget System

**What it does:**
- Assigns energy points based on your daily level:
  - High = 8 points
  - Medium = 5 points
  - Low = 3 points
- Calculates task costs:
  - Deep Work = 3 points
  - Medium = 2 points
  - Light = 1 point

**How it helps:**
- Warns when you're overbooked
- Prevents burnout
- Encourages realistic planning

**Example:**
```
You: Add 3 Deep Work tasks (9 points) on a Medium energy day (5 points)
Zenith: "⚠️ Energy overbooked! You have 9 points of tasks but only 
         5 energy points available."
```

#### 4. Goal Health Scoring

**What it does:**
- Scores each goal 0-100 based on:
  - Recent activity (last 7 days)
  - Progress rate (completed vs total tasks)
  - Task count (goals need actionable tasks)

**How it helps:**
- Identifies stalled goals automatically
- Provides actionable recommendations
- Keeps you accountable

**Example:**
```
Goal: "Learn React" — Score: 35 (Stalled)
Recommendation: "No recent activity. Schedule a task this week."
```

#### 5. Smart Task Breakdown

**What it does:**
- Detects tasks over 2 hours
- Suggests breaking into subtasks
- Auto-suggests subtasks from templates

**How it helps:**
- Prevents overwhelm
- Improves focus
- Increases completion rate

**Example:**
```
You: Create task "Code authentication feature" (240 minutes)
Zenith: "⚠️ This task is quite long. Consider breaking it down."
        Suggests: Design → Implement → Test → Review → Deploy
```

#### 6. Distraction Analytics

**What it does:**
- Categorizes every distraction:
  - Digital (notifications, phone, email)
  - Social (people, colleagues, calls)
  - Internal (thoughts, worries, ideas)
  - Physical (noise, temperature, discomfort)
- Tracks weekly patterns

**How it helps:**
- Identifies your top distraction type
- Provides weekly insights
- Helps you build better focus habits

**Example:**
```
Weekly Report:
- Total distractions: 23
- Top type: Digital (12 times)
- Recommendation: "Turn off notifications during focus sessions"
```

## 🔒 Privacy & Data

### What Data is Stored?

All data is stored **locally in your browser** using localStorage:
- Tasks, goals, habits
- Energy levels and patterns
- Pomodoro sessions
- Analytics and insights
- Theme preferences

### What Data is Sent to Servers?

**Nothing.** Zenith is 100% offline and private:
- No account required
- No data sent to any server
- No tracking or analytics
- No cookies (except localStorage)

### Backing Up Your Data

**Important:** Browser data can be lost if you:
- Clear browser cache/data
- Uninstall browser
- Use incognito mode

**Recommendation:**
- Export your data weekly
- Save the JSON file to cloud storage (Dropbox, Google Drive, etc.)
- Keep multiple backups

## 🐛 Troubleshooting

### Morning Ritual Keeps Appearing

**Cause:** You're in a new day but haven't completed the ritual.

**Solution:**
- Complete the ritual (takes 2-3 minutes)
- Or click "Skip ritual" to dismiss it

### Tasks Not Showing

**Check:**
1. Are you on the correct date? (Check calendar)
2. Is the sidebar view set to "Today"? (Try "All")
3. Are tasks filtered by a specific category?

### Pomodoro Not Starting

**Check:**
1. Is the timer already running?
2. Try refreshing the page
3. Check browser console for errors (F12)

### Data Lost After Browser Update

**Cause:** Browser cleared localStorage.

**Solution:**
- Import your last backup (if you have one)
- Unfortunately, data cannot be recovered without a backup
- **Prevention:** Export data regularly

### Themes Look Weird

**Try:**
1. Switch to a different theme
2. Toggle dark/light mode
3. Adjust animation quality
4. Refresh the page

## 🆘 FAQ

### Is Zenith free?

Yes, completely free and open source.

### Do I need an internet connection?

No, Zenith works 100% offline after the initial load.

### Can I use Zenith on mobile?

Yes! It's responsive and works on phones and tablets. For best experience, use a tablet or desktop.

### Can I sync across devices?

Not automatically. But you can:
1. Export data from Device A
2. Transfer the JSON file (email, cloud, etc.)
3. Import on Device B

### How do I update to a new version?

1. Export your data from the old version
2. Download the new HTML file
3. Open it and import your data

### Can I customize the themes?

Yes! The HTML file contains all CSS. You can edit the theme variables in the `<style>` section.

### What browsers are supported?

- Chrome/Edge (recommended)
- Firefox
- Safari
- Any modern browser with ES6+ support

### Can I use this for team collaboration?

Zenith is designed for personal use. For teams, consider:
- Each person uses their own instance
- Share goals/tasks via export/import
- Use a shared cloud folder for JSON files
