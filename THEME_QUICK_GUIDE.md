## 🎨 Heatmap Visibility Guide

### Dark Mode Heatmaps
All themes have **excellent visibility** in dark mode:
- Empty cells: Subtle theme-colored background
- L1 (Low): 35% opacity + soft glow
- L2 (Medium): 60% opacity + medium glow
- L3 (High): 80% opacity + strong glow
- L4 (Very High): 95% opacity + bright glow

### Light Mode Heatmaps
All themes have **perfect visibility** in light mode:
- Empty cells: Light theme-colored background
- L1 (Low): 25% opacity + clear border
- L2 (Medium): 45% opacity + defined border
- L3 (High): 65% opacity + strong border
- L4 (Very High): 85% opacity + bold border

### Hover Effects
- **Scale**: 1.15x (15% larger)
- **Glow**: Theme-specific color

- **Transition**: Smooth 0.25s

## 💡 Pro Tips

### Theme Switching
1. Click 🎨 icon in top-right
2. Select theme instantly
3. Toggle ☀️/🌙 for light/dark
4. Changes save automatically

### Customization
1. Open DevTools (F12)
2. Find CSS variables (lines 180-400)
3. Edit in real-time
4. Copy changes to save

### Best Practices
- **Match your energy**: Use Forest when energized, Ocean when calm
- **Match the time**: Dark modes for night, light for day
- **Match the task**: Midnight for code, Sakura for creative
- **Experiment**: Try each theme for a day
- **Listen to your eyes**: If straining, switch modes

### Accessibility
- All themes are WCAG AA compliant
- High contrast in both modes
- Color-blind friendly progressions
- Clear visual hierarchy
- Readable at all sizes
